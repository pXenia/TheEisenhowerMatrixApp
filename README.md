# Матрица Эйзенхауэра - Мобильное приложение для Android

Мобильное приложение для управления задачами с использованием матрицы Эйзенхауэра, разработанное для операционной системы Android.

## Описание

Матрица Эйзенхауэра позволяет эффективно организовывать задачи, разделяя их на 4 квадранта в зависимости от важности и срочности. 

## Технологический стек

- Язык программирования: Kotlin
- UI Framework: Jetpack Compose
- Dependency Injection: Dagger Hilt
- Асинхронность: Kotlin Flow, Coroutines
- Сетевые запросы: Retrofit
- Сериализация: Gson

## Основная функциональность

### Матрица Эйзенхауэра
- Q1 (Срочное и Важное) - задачи, требующие немедленного выполнения
- Q2 (Важное, но не срочное) - стратегические задачи для планирования
- Q3 (Срочное, но не важное) - задачи для делегирования
- Q4 (Не срочное и не важное) - задачи с низким приоритетом

### Управление задачами
- Создание новых задач
- Редактирование существующих задач
- Удаление задач
- Просмотр списка всех задач
- Отметка задач как выполненных
- Установка дедлайнов
